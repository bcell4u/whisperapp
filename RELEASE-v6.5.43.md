# WhisperRecorder v6.5.43 — Decoder prepacking A/B and KV-cache accounting

This release keeps the proven Qualcomm QNN FP16 encoder + CPU FP32 ONNX decoder unchanged by default. The previous v6.5.42 A/B showed that turning OFF the CPU arena reduced PSS by about 472 MiB but did not improve transcription speed, so CPU arena remains ON by default. Its control is now in Qwen Advanced instead of the main model card.

**New narrowly scoped memory experiment:** An opt-in **weight prepacking OFF** switch under Qwen Advanced adds ONNX Runtime 1.27's documented `session.disable_prepacking=1` to *both* decoder CPU sessions before they load. Both baseline and experimental runs continue to use identical original ONNX graphs, shared on-disk FP16 weights, and unchanged KV input/output behavior. It is not yet known how much prepacking contributes to the observed ~2.22-GiB rise from loading the second session, whether memory will decrease, or whether CPU inference will slow down. Setting defaults to OFF (normal ORT prepacking enabled). Do not combine arena-OFF with prepacking-OFF in the first test.

**KV status:** J75 quantified FP16 KV payload; J76 verified fixed-position and nonzero KV inputs provisionally; J74/J85 ran position-8 graph calls. Persistent NPU-resident KV, real growing-cache NPU decoding, and 28-layer NPU decoding have **not** been implemented or measured. Android CPU decoding already forwards native `OnnxTensor` KV outputs directly as the next step's inputs, without a Java-side full-cache array copy. That does not guarantee no internal ORT memory traffic.

**KV diagnostics:** For each 12-second segment, report initial/last logical combined past-key + past-value tensor payload, sum of logical input payloads presented to token-step inference, sample count, and growth/shrink steps. These are **shape-derived logical payload estimates, not measured DRAM bytes, actual copies, allocations, PCIe/NPU transfers, or CPU time**. Numeric counters only; no patient audio, transcript text, raw token IDs, paths, or personal information.

The configuration AIDL handshake advances to schema 2 with explicit requested/applied prepacking state, fails closed on mismatches, and never relies on worker-side SharedPreferences. Default 2/4 CPU thread behavior, safe verified FP16 embeddings, cleanup and diagnostics in user-selected `Whisperapp/Logs`, and Parakeet/Omi/Whisper backends are preserved. No new QNN compile, model conversion, dependency, or app storage migration.

Version: 6.5.43, Android version code 65043. Source verification and archive integrity run locally; full GitHub Gradle and real S26 A/B remain pending. If prepacking OFF provides no major memory savings or degrades runtime materially, stop this experiment and retain standard ORT prepacking.
