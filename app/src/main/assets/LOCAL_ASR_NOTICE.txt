Whisper Recorder v6.7.0 local ASR notices

Model weights are NOT bundled with the application. They are downloaded only after the user chooses a model.

NVIDIA Parakeet-TDT 0.6B v3
- Upstream model: NVIDIA Parakeet-TDT 0.6B v3
- Authoritative source: https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3
- Runtime-compatible GGUF conversion: mudler/parakeet-cpp-gguf
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- Runtime: parakeet.cpp v0.5.0
- Production GPU execution: Qualcomm/OpenCL GPU automatically when the Q8_0 GPU model is selected.
- Optional Qualcomm NPU FP16 package: drinnird/parakeet-tdt-0.6b-v3-sm8850-v81-fp16; execution uses ORT-QNN/HTP on the validated SM8850/V81 target. The NPU package is downloaded separately and is not bundled in the APK.

Omi Med STT v1 (0.6B)
- Model/weights: Omi Health, omi-health/omi-med-stt-v1 and omi-health/omi-med-stt-v1-gguf
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- Base model: NVIDIA Parakeet-TDT 0.6B v2
- Omi Q8_0 uses the same patched parakeet.cpp v0.5.0 OpenCL/Adreno runtime as NVIDIA Parakeet; the Omi medical adapter is enabled only when its GGUF metadata/tensors are present.
- Omi Med STT v1 is speech-to-text only and is not clinically validated. Transcripts require review before clinical use.

Qwen3-ASR 0.6B
- Upstream model: Qwen/Qwen3-ASR-0.6B (Apache License 2.0).
- GGUF decoder: ggml-org/Qwen3-ASR-0.6B-GGUF (Q8_0, 804,749,248 bytes).
- Device-specific encoder: drinnird/qwen3-asr-0.6b-snapdragon-sm8850-v81 (~391 MB, includes tokenizer).
- Runtime: Qualcomm ORT-QNN/HTP encoder + pinned llama.cpp v0.6.0 ARM64 Q8_0 dotprod decoder.
- Complete on-demand installation: ~1.20 GB; no model weights bundled.
- Qualification is currently restricted to Samsung Galaxy S26 SM-S942U; no QNN CPU fallback.
